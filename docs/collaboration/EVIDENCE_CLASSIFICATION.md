# Evidence Classification

This document defines the classification scheme for artifacts recorded in the [Evidence Log](EVIDENCE_LOG.md).

## Artifact Types

| Type | Code | Description |
|------|------|-------------|
| Documentation | `DOC` | README files, policy documents, guides, templates |
| Code | `CODE` | Source code, scripts, configuration files |
| Governance | `GOV` | Governance decisions, policy changes, voting records |
| Analysis | `ANLYS` | Reports, audits, analysis outputs |
| Communication | `COMM` | Decisions recorded from discussions, issues, or PRs |
| Collaboration Event | `COLLAB` | Logged events of Human + AI collaboration |

## Origin Labels

| Label | Meaning |
|-------|---------|
| `human` | Created entirely by a human contributor |
| `ai-assisted` | Created or substantially edited with AI assistance, reviewed by human |
| `ai-generated` | Drafted by AI, reviewed and approved by human |
| `automated` | Generated by an automated pipeline (e.g., CI/CD) |

## Sensitivity Levels

| Level | Meaning |
|-------|---------|
| `public` | Safe to share openly |
| `internal` | For project contributors only |
| `restricted` | Limited to maintainers |

## Usage

Each entry in the Evidence Log should include:
- **Type code** from the Artifact Types table above
- **Origin label** indicating the degree of human vs. AI authorship
- **Sensitivity level** appropriate to the content
