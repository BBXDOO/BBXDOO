# BBXDOO — Personal Design Sandbox

พื้นที่ทำงานส่วนตัวของ BBX19 สำหรับออกแบบ ทดลอง ศึกษา และปรับโครงสร้าง W3

## ความสัมพันธ์กับ W3

พื้นที่นี้เริ่มจากสำเนาของ [W3_HB_team_BXCGICOG — refactor/v0.2](https://github.com/BBXDOO/W3_HB_team_BXCGICOG/tree/refactor/v0.2) ณ commit `d2a87201b65a2ea07a0899e6d62c09769787eb51` เมื่อ 22 กันยายน 2026

ทั้งสองรีโปเป็นอิสระจากกัน การแก้ในพื้นที่นี้ไม่เปลี่ยน W3 และการแก้ใน W3 ก็ไม่เข้ามาที่นี่เอง การนำงานข้ามรีโปต้องทำโดยตั้งใจและตรวจทานก่อน

## ใช้พื้นที่นี้อย่างไร

- เก็บแนวคิด แบบร่าง โค้ดต้นแบบ และการทดลองส่วนตัว
- ทดสอบหรือแก้โครงสร้างได้โดยไม่กระทบรีโป W3
- อ้างอิงไฟล์เดิมของ W3 ได้ โดยยังรักษาประวัติและเจตนาของงานทดลอง

## สถานะ

- สาขาทำงาน: `refactor/v0.2`
- เป็นพื้นที่ทดลองส่วนตัว ไม่ใช่สถานะปัจจุบันของรีโป W3
- ไม่มีการ deploy PWA หรือ GitHub Pages จากสาขานี้
